Session 1 ( notes ) 

What and why Python?: High-level programming language, it is object-oriented, interpreted and interactive
 - Object orientation is a programming paradigm, whereby data and functionality are encapsulated into objects, and you write code to manipulate those objects
 - Python code is converted on the fly to low-level instructions for the computer
What and why Python?: General-purpose programming language, widely used for scripting, some standard uses include:
- Teaching programming, Web development, Biosciences, Machine learning, neural nets,  Natural Language Processing
